# Ahmed's standing rules (read hub/INDEX.md first)
## Delegation
- Cheapest model per task: architect (Opus) plans, builder (Sonnet) writes code, runner (Haiku) builds, tests, uploads.
- Briefs under 10 lines. Replies short and firm, no cheerleading.
- Escalate one level only after a cheaper agent fails twice on the same thing.
## Style
- No em dashes. No new icons unless asked. Free plans only.
- Calm dark glass minimalist theme. Keep the theme exactly, do not re-theme.
- Hold, swipe and drag over buttons. Reordering is always a gesture, never Move up/down.
- Do what was asked, nothing more. Extra ideas go in as a short suggestion.
## Publish and data
- Publish without asking when tests pass.
- Data changes only with a backup, a rollback and his "go".
- Logged time is billable and never deleted (soft delete only).
## Edit queue policy
- New edits go in app/EDIT_QUEUE.md, run in the window Tue 18:00 to Wed 18:00 Egypt time.
- Only the word "vital" overrides the queue. Vital = loses or hides data or billable time, breaks sync, blocks work, security.
## Design principle (his words, 28 Nov)
- The optimum app is not the complete app: it lowers cognitive load with the fewest features. Every new feature must replace or remove something. Retire unused features (hide, never delete data).
